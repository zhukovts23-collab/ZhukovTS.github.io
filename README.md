# GameVerse

Игровой портал на PHP 8.3, MySQL 8 / MariaDB 10.11 и обычном HTML/CSS/JavaScript. Существующие страницы и бренд сохранены, серверные сервисы перенесены из localStorage в общую БД.

**Размещение:** эта ветка требует PHP-хостинга. GitHub Pages PHP не исполняет. Не переключайте действующий Pages на эту ветку до развёртывания серверной версии.

## Состав

- XML-справочник из 50 игровых терминов (6 полей), PHP/XSLT, фильтрация и сортировка;
- 20 самостоятельных статических материалов и 10 сервисов;
- игры только в MySQL: сведения о БД, ввод и редактирование, поиск по жанру и синхронизированной платформе, статистика;
- MySQL-каталог, пять типов SQL-запросов, диаграммы и агрегаты;
- новости, форум с ответами, гостевая книга и модерация, оценки, опрос и посещения в БД;
- единый раздел RSS с формами добавления источника и новости, MySQL-хранение, объединение и экспорт RSS/XML/CSV/CSV-в-XML;
- API игрового бюджета на курсах ЦБ, российский погодный RSS;
- локальные изображения, общее меню и поиск, тест знаний и калькулятор загрузки;
- авторизация администратора, CSRF, PDO-параметры, ограничения частоты и безопасный XML.

## Быстрый запуск через Docker

1. Скопировать `.env.example` в `.env`, задать уникальные секреты и адрес.
2. `docker compose up -d --build`
3. Передать пароль администратора через окружение (не сохранять в репозитории):
   `docker compose exec -e ADMIN_PASSWORD web php bin/install.php`
4. `docker compose exec web php bin/configure-url.php`
5. Открыть `http://localhost:8080`; управление — `/admin.html`, логин `admin`.

В команде 3 переменная ADMIN_PASSWORD должна быть установлена в текущем окружении, минимум 14 символов. Установщик CLI повторно не затирает существующие новости и пароль.

Полная браузерная проверка PHP-хостинга, настройка HTTPS, регистрация в поисковиках и проверка из РФ выполняются после предоставления хостинга. Автоматическая индексация и оценка преподавателя не гарантируются.
