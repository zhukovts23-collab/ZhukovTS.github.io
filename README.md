# GameVerse

GameVerse — статический медиа-сайт о видеоиграх.

## Разделы
- каталог игр
- жанры
- платформы
- обзоры
- киберспорт
- галерея
- коллекция ссылок
- интерактивные сервисы

## Сервисы
Поиск по сайту, гостевая книга, форум, публикация новостей, рейтинг игр и статистика посещений.

## Запуск
Откройте `index.html` локально или разместите содержимое каталога на статическом хостинге. Все внутренние ссылки используют относительные пути.
