Данные GameVerse

База данных

Модель данных для каталога игр и редакционных новостей, рассчитанная на подключение к серверной БД и подготовку RSS.

Каталог видеоигр

Основные поля игры: идентификатор, название, жанр, год выпуска, платформы и редакционная оценка.

ПолеНазначение
game_idУникальный идентификатор
titleНазвание
genre_idСвязь с жанром
release_yearГод выпуска
platformsПлатформы
ratingОценка от 0 до 5

Редакционные новости

Новости связаны с автором, статусом публикации и датами. В RSS должны попадать только опубликованные записи.

ПолеНазначение
news_idУникальный идентификатор
titleЗаголовок
bodyТекст новости
published_atДата публикации
statusЧерновик / публикация / архив

SQL-схема

Файл подготавливает таблицы genres, games и news.

Посмотреть SQL-схемуСкачать schema.sqlXML-каталогRSS-лента

GitHub Pages — статический хостинг. Для общего хранения новостей нужна серверная часть/API и подключённая база данных; SQL-файл является основой для неё, а не работающей БД.
