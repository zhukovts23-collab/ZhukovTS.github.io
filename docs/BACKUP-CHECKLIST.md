# GameVerse: сохранение актуальной копии

Текущий сайт и админка проверены пользователем 4 ноября 2026 года. Следующий шаг — сохранить файлы и текущую базу вне хостинга. Код в GitHub и первоначальный SQL не содержат всех новых публикаций, сообщений, голосов и оценок.

Сессия панели в облачном браузере завершена; последняя попытка повторного входа не завершилась. Резервная копия пока не получена. Можно скачать её в обычном браузере пользователя без PowerShell.

## Скачать два файла

1. Открыть панель Спринтхост и раздел «Базы данных».
2. Нажать имя `ramzesss_gameverse`, затем **«Скачать резервную копию»**. Сохранить полученный файл на компьютер.
3. Открыть «Файлы», перейти в папку `domains` из домашнего каталога аккаунта.
4. Отметить галочкой папку `ramzesss.xsph.ru` и нажать кнопку **«Скачать файл»** со стрелкой вниз. Сохранить архив на компьютер. Отмечается вся папка сайта, чтобы сохранить public_html вместе со скрытыми настройками.
5. Передать оба файла для проверки полноты и сохранения копии вне хостинга. Распаковывать их или копировать содержимое настроек в переписку не нужно.

Архив сайта содержит закрытые настройки подключения. Его и дамп текущей базы нельзя публиковать в открытом репозитории или размещать в публичном каталоге сайта. В исходники GitHub попадают только общие инструкции и схема без рабочих секретов.

Официальная инструкция хостинга: https://help.sprinthost.ru/faq/backups — раздел «Как скачать актуальную копию сайта?». Копии, сделанные до последних проверок форм, не заменяют свежую выгрузку.

## Проверить после получения

- Архивы открываются без ошибок и содержат непустые файлы.
- В копии сайта есть HTML, CSS, JS, локальная графика, games.xml/games.xsl, api, app, database и корневой .htaccess. Наличие приватной конфигурации проверяется без вывода её содержимого.
- Дамп содержит все таблицы текущего сайта, включая admins, messages, news, ratings, votes, visits и обе steam_pulse-таблицы. Проверяются количества и структура без публикации паролей, хешей и закрытых данных.
- Свежая новость, сообщения форума/гостевой и результаты голосований присутствуют в выгрузке. Точные идентификаторы определяются только по полученным файлам.
- Сохранена отдельная копия вне аккаунта хостинга и инструкция переноса с импортом в новую пустую базу. Возможность восстановления оценивается по фактической проверке; до неё копия не считается проверенной.

Отключать хостинг, удалять сайт или перезаписывать текущую базу на этом этапе не требуется.
