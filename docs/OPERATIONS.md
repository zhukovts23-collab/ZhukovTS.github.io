# Эксплуатация и передача знаний

## Архитектура

HTML/CSS/JS → api/index.php → PDO → MySQL. Внешние данные читаются только сервером с фиксированных HTTPS-адресов. api/xml.php использует локальные games.xml и games.xsl; api/export.php формирует обменные документы из БД и RSS.

## База

- games: 20 игр, строковый PK; rating — редакционная оценка, отдельно от пользовательских оценок.
- news: собственные публикации и дата создания.
- admins: логин и password_hash; в исходниках нет рабочего пароля.
- messages: guest/forum/reply, self-reference parent_id с каскадным удалением; visible для модерации.
- ratings: PK(game_id,visitor), score 1–5; votes: один жанр на visitor.
- visits: путь, случайный идентификатор сеанса, дата; персональные IP не хранятся.
- blocked_words / blocked_hosts: запреты; host_hash — HMAC адреса подключения с серверным secret.
- cache: бинарный XML и дата. MEDIUMBLOB необходим, поскольку ЦБ возвращает windows-1251. XML-парсер читает кодировку из декларации.
- rate_limits: счётчики по HMAC адреса, операции и временному окну.

## API

Все маршруты: api/index.php?action=ИМЯ. Ответы JSON, ошибки — объект error и код 400/401/403/404/405/429/503. GET session выдаёт CSRF и статус авторизации. Все POST передают X-CSRF-Token и JSON с cookies того же сайта. Чужие домены не получают разрешение CORS.

| GET | Назначение |
|---|---|
| games?q=&genre=&sort=title/year/rating | Каталог |
| analytics | Сводные показатели и группировки |
| news / messages?kind=guest/forum | Публикации и сообщения |
| ratings / poll / stats | Оценки, опрос и посещаемость |
| rates | Курсы на дату ЦБ |
| budget?amount=59.99&currency=USD&fee=0 | Расчёт с комиссией |
| weather | Прогноз Москвы и области |
| feed | Объединённая лента и состояние внешнего источника |
| admin_data | Модерация, только администратор |

POST: login, logout, news_save, message, moderate, block_word, block_host, rate, vote, visit. Форматы полей показаны в js/site.js и tests/integration.py. Сервер валидирует длины, типы и разрешённые значения; сортировка и источники выбираются из фиксированного списка.

## Эксплуатация

1. Регулярно сохранять БД и конфигурацию отдельно от публичного каталога.
2. Проверять журналы PHP при 503; посетителю не показываются SQL и секреты.
3. Контролировать место в БД. Удалять устаревшие rate_limits (например, старше 2 суток: текущие окна имеют 300/900 секунд), посещения — по принятому сроку хранения. Сделать резервную копию перед очисткой.
4. Кэш ЦБ живёт 6 часов, RSS 15 минут, погода 30 минут. На первом запросе после истечения запрашивается источник. При сбое используется сохранённый XML с stale=true. При отсутствии кэша — явная ошибка; числа не выдумываются.
5. Администратор работает через admin.html; срок авторизации 2 часа. Пароль менять CLI с password_hash/PASSWORD_DEFAULT, никогда не записывать его открытым текстом в БД или git.
6. За обратным прокси REMOTE_ADDR может быть адресом прокси. Доверенные адреса и mod_remoteip настраивает хостинг. Не доверять произвольному X-Forwarded-For из пользовательского запроса.
7. Фото сохранены из существующего сайта; происхождение записано в ASSETS.md. Подписи галереи не выдают атмосферные фото за игровые скриншоты.

## Ограничения

Сеанс можно сбросить удалением cookie; это не система идентификации человека. Опрос и оценки не рассчитаны на противодействие организованной накрутке. Антиспам ограничивает частоту и даёт инструменты модерации. Для массовой аудитории потребуются аккаунты, расширенный мониторинг и резервное копирование по расписанию.

Год означает первый выпуск игры; список платформ не претендует на каталог текущих магазинов. Проект не продаёт игры и не обещает доступность оплаты. Внешний RSS iXBT включает технологические новости, что явно указано в интерфейсе.
