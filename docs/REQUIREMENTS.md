## Лабораторная 2

20 объектов game, 6 дочерних тегов и атрибут id. Отдельный games.xsl. api/xml.php загружает XML и применяет XSLT на PHP. Фильтры: название и жанр; сортировки: название, год, оценка. В соответствии с персональным замечанием преподавателя предмет XML — каталог игр. Документирован источник данных и субъективный характер редакционных оценок.

## Лабораторная 3

MySQL/MariaDB и PHP PDO. Пять типов выборок: фильтрация/сортировка каталога; агрегаты COUNT/AVG/MIN/MAX; GROUP BY genre; GROUP BY year; TOP-5. database.html показывает числовые показатели и диаграммы, games.html — таблицу. Дополнительные операции INSERT/UPDATE работают для новостей, сообщений и оценок.

## Лабораторная 4

Импорт RSS iXBT и чтение news из БД, объединение, удаление дублей по URL, сортировка по времени. Экспорт RSS 2.0, XML, CSV с разделителем и заголовком, CSV внутри XML. UTF-8 выбран вместо буквального ASCII, чтобы сохранить русский текст. Прикладная обработка экспорта проверяется обратным разбором XML и CSV в интеграционном тесте. Полные сторонние статьи не копируются: заголовок и ссылка на источник.

## Дополнительный API-сервис

«Игровой бюджет»: внешний XML API Банка России → серверный кэш → расчёт → собственный JSON API → интерфейс. Поддерживает комиссию, номиналы валют, дату курса и признак устаревшего кэша. knowledge.html описывает контракт, алгоритм, ошибки, безопасность и накопленный опыт. Решение о зачёте дополнительного сервиса и автомате принимает преподаватель.
