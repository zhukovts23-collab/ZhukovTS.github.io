## Что эта проверка не подтверждает

- Автоматические запросы выполнены с сервера хостинга. Для перечисленных выше интерфейсов есть подтверждение пользователя; это не проверка всех страниц во всех браузерах. Облачный браузер автоматически меняет HTTP на HTTPS и не открывает этот тестовый адрес.
- HTTPS-проверка с сервера завершилась без HTTP-ответа. Действующий адрес приложения использует HTTP.
- Вход и административные действия подтверждены пользователем. Ассистент не выполнял повторный вход с его паролем и не перепроверял новые строки базы после этого подтверждения.
- Последние новости и сообщения прежнего сайта на Beget не перенесены: для них нужна свежая копия старой базы. Состояние старого сайта не заменено начальным наполнением нового.
- Доступность sitemap.xml не означает принятие карты поисковиком. Индексация нового адреса и успешная обработка карт поисковой системой не подтверждены.
- Свежая полная резервная копия файлов и текущей базы вне хостинга ещё не сохранена: попытка повторного входа в панель не завершилась. Исходники в GitHub и первоначальный SQL не заменяют копию новых сообщений, голосов и настроек.

Для повторной проверки скрипт запускается только через CLI. При наличии `app/verification.result.json` он завершает работу без повторных запросов. Отчёт содержит статусы и публичные данные; пароли, хеши паролей и секрет приложения в него не записываются.
