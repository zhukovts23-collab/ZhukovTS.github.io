# Проверка версии — 28 октября 2026

## Подтверждено

PHP 8.3.6, MariaDB 10.11.14, отдельная тестовая БД. `tests/integration.py` выполнил **38 проверок** через реальные PHP-контроллеры и PDO. HTTP-ввод моделируется CLI-harness tests/request.php; это не замена проверке Apache и cookies в браузере.

Проверены 20 записей, SQL-фильтрация/сортировка, защита от SQL-инъекции, агрегаты и TOP-5, серверный XSLT и экранирование параметров, CSRF, запрет анонимной публикации, новости администратора, гостевая книга, форум/ответы, диапазон и замена оценки, замена голоса в опросе, посещения, пароль, вход/выход администратора, скрытие/восстановление сообщений, запрещённые выражения, RSS/XML/CSV и CSV-в-XML с обратным разбором.

Живые внешние запросы: API ЦБ, RSS прогноза Москвы Гидрометцентра и RSS iXBT. Проверены расчёт бюджета, объединение двух источников и экспорт объединённого RSS. Исправлены кодировка кэша ЦБ (MEDIUMBLOB), адрес прогноза без завершающего слеша, конечный адрес RSS iXBT и сохранение всех элементов SimpleXML при преобразовании в массив.

Синтаксис всех PHP-файлов проверен `php -l`, JavaScript — `node --check`. Проверены 711 локальных ссылок/ресурсов: отсутствующих файлов нет. Все 6 изображений галереи загружены в браузере. Проверены общая навигация, вид главной и поиск «кооператив», который находит It Takes Two и Portal 2.

HTML: все 25 страниц прошли Nu HTML Checker (`vnu.jar --errors-only`) без ошибок после исправления иерархии заголовков.

## Границы проверки

- Браузерный предпросмотр среды не смог исполнить установленный PHP-бинарник. В браузере проверялась статическая часть; серверные контроллеры проверялись отдельно с MariaDB.
- Не выполнена HTTP-проверка связки Apache/PHP, .htaccess, HTTPS и secure-cookie на целевом хостинге.
- Docker Compose описан, но не запущен в данной среде.
- Подключение из России не использовалось; доступность конкретных российских провайдеров не подтверждена.
- Аккаунт PHP-хостинга отсутствует. Публичная PHP-версия ещё не размещена. Действующий GitHub Pages не заменён.
- Регистрация окончательного адреса в Яндекс/Google, индексация и поисковые позиции не подтверждены.

1. HTTPS и 403/404 для закрытых каталогов и .env.
2. Войти администратором; создать новость; проверить её в другом браузере и RSS.

## Повторный интеграционный запуск

Использовать только отдельную БД для тестов: сценарии создают тестовые публикации и оценки. Установить DB_DSN, DB_USER, DB_PASSWORD, APP_SECRET, ADMIN_PASSWORD; выполнить `php bin/install.php`, затем `python3 tests/integration.py`. При отдельном PHP-бинарнике можно задать TEST_PHP и TEST_PHP_INI. Повторять на чистой тестовой БД. Тесты никогда не запускать против публичной БД.
